Text Mining Case Study

PDF to WordCloud

An educational Python workflow that extracts PDF text, cleans it with stopword and punctuation removal, and turns word frequency into a WordCloud visualization.

Pipeline

PDF extraction → text cleaning → stopword removal → cleaned text → WordCloud.

Tools

Python, pdfplumber, NLTK, wordcloud, matplotlib and Jupyter.

Output

The repository includes cleaned text, a generated WordCloud image, a notebook and a project report.
